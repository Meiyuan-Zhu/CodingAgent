# 开发记录入口

本目录记录开发事实和后续工作，不是产品运行时的 Agent 记忆，也不保存凭据、原始聊天或未经审核的运行日志。

## 文档职责

| 文件 | 用途 | 维护方式 |
| --- | --- | --- |
| [STATUS.md](STATUS.md) | 当前已完成、进行中、待实现与下一步 | 每个有意义的阶段更新，唯一状态汇总 |
| [PROJECT_PLAN.md](PROJECT_PLAN.md) | 需求、范围、架构建议和排期 | 范围或方案变化时更新，不能当完成记录 |
| [DEVLOG.md](DEVLOG.md) | 实际开发过程和阶段变化 | 追加事实，保留历史 |
| [VERIFICATION.md](VERIFICATION.md) | 检查方法、范围、结果和限制 | 每次有意义的验证后追加，过期结果标明 |
| [决策索引](../decisions/README.md) | 为什么这样做、备选与代价 | 重要决策变更时维护 |
| [AGENTS.md](../AGENTS.md) | 后续开发的工作约定 | 工作规则变化时维护 |

## 继续开发时

先看 STATUS，再按任务读相关决策、代码与测试。若记录和代码不一致，以核查结果修正记录，不按旧描述推断功能存在。

后续接口合同、架构细节和面试材料也放在本目录，但只在有内容时创建。真实模型运行日志使用独立的本地运行目录；仅将审核过的证据摘要纳入版本控制。

每个实现阶段结束时，更新状态、追加开发变化与验证证据；若涉及重要取舍，再补决策。不要在多个文件复制一份“已完成清单”。
